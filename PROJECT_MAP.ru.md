# Карта проекта `zerokull-c11-go` (Путеводитель по папкам и файлам)

Этот проект — чистый, переносимый и легко читаемый порт движка на стандартном языке **ISO C11**, ядерном **eBPF/XDP** (`libbpf`) и пульте управления на **Go** (плюс вспомогательный SSH-радар на Rust).

---

## Полка 1. Ядерный фильтр на входе (`bpf/`)

| Путь к файлу | Что делает простыми словами |
| :--- | :--- |
| `bpf/xdp_guard.bpf.c` | Программа, которая загружается внутрь ядра Linux на сетевую карту. Отбрасывает атаки (`XDP_DROP`) на уровне L2–L4 (поддельные IP, `VLAN VID=0`, `TCP/2049` NFS2ROOT, `UDP/443` QUIC, сканеры Nmap), ведёт чёрный/белый списки в `LRU`-картах и отправляет подозрительные пакеты в кольцевой буфер `BPF_MAP_TYPE_RINGBUF`. |

---

## Полка 2. Заголовки и общие структуры (`include/`)

| Путь к файлу | Что делает простыми словами |
| :--- | :--- |
| `include/zerokull.h` | Общий «словарь» между ядром Linux, C-движком и Go-пультом: описывает форматы событий, статистику в общей памяти `/dev/shm/zerokull_stats`, коды вердиктов (`PASS`, `DROP`, `BAN`) и 4-банковый ячеистый карантин. |
| `include/zk_policy.h` | Описание настроек из файла `/etc/zeromani/policy.conf` (режим `enforce`/`shadow`, привязка к ядрам CPU, белые и чёрные списки). |
| `include/zk_gpu_ring.h` | Кольцевой буфер для опциональной разгрузки тяжёлых проверок на видеокарту без копирования памяти. |

---

## Полка 3. Основной движок на чистом C11 (`src/`)

| Путь к файлу | Что делает простыми словами |
| :--- | :--- |
| `src/engine.c` | **Главный мозг фильтрации (L2–L7)**: разбирает заголовки Ethernet/VLAN/IPv4/IPv6/TCP/UDP, ловит HTTP Smuggling, обход путей (`..;/`, `%2e`), PHP/CMS инъекции, утечки DNS, аномалии `RFC 793` и скрытые энтропийные туннели (через `POPCNT` и сдвиг фаз). |
| `src/daemon.c` | Системный демон `zerokull-daemon`: загружает `xdp_guard.bpf.c` в ядро, читает пакеты из кольцевого буфера, передаёт их в `engine.c`, автоматически банит атакующих в карте ядра и обновляет статистику в `/dev/shm`. Поддерживает перезагрузку конфига по сигналу `SIGHUP`. |
| `src/stat.c` | Сверхлёгкая консольная утилита `zerokull-stat`: мгновенно читает счётчики пакетов из `/dev/shm/zerokull_stats` без единого системного вызова в ядро. |
| `src/zk_gpu_ring.c` | Реализация безопасного кольца отправки батчей на GPU с защитой от переполнения. |

---

## Полка 4. Пульт управления, SSH-радар и тесты (`cmd/`, `rust_tui/`, `tests/`, `tools/`)

| Путь к файлу | Что делает простыми словами |
| :--- | :--- |
| `cmd/zerokull-ctl/main.go` | Пульт управления на **Go** (`zerokull-ctl`): показывает статус, отдаёт метрики в **Prometheus** (`/metrics`), JSON API и отправляет тревоги в **SIEM** по сети (Syslog RFC 5424 и ArcSight CEF). |
| `rust_tui/` | Безопасный парсер файла `policy.conf` и интерактивный терминальный радар **`zero-tui`** на Rust (для управления сервером по SSH без графического интерфейса). |
| `tests/test_suite.c` | Набор автоматических тестов (51+ сценарий атак и чистого трафика), который проверяется под санитайзерами памяти `ASan` и `UBSan`. |
| `tools/demo_audit_30s.sh` | Демонстрационный стенд в 1 команду: поднимает виртуальную сеть, пропускает реальные атаки через XDP-фильтр и выводит отчёт. |
| `deploy/` | Конфиг по умолчанию (`policy.conf`), systemd-юнит и скрипт безопасной установки (`install.sh`) с проверкой подписи `SHA-256`. |
